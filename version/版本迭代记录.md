# PiliExo 版本迭代记录

## v26.8.28.2（2026-08-28）

[新增] 外观设置新增磨砂半透明总开关，提供轻薄、标准、浓厚三档效果，覆盖顶栏、主底栏、浮动底栏和特殊页面 AppBar。
[新增] 震动反馈设置新增 1–255 强度调节，拖动滑块时即时反馈；新安装默认开启，默认强度为 80。
[更改] Android 正式包使用独立 applicationId `com.maxzrb.piliexo`，Release 按 `armeabi-v7a`、`arm64-v8a` 分包并启用 R8 与资源压缩。
[更改] Android 更新优先使用 AerithDream/PiliExo ModelScope 镜像，无法连接时回退 GitHub Release。
[更改] 普通视频默认画质顺序调整为 8K、HDR Vivid、杜比视界、HDR 真彩；蜂窝网络文案改为“移动数据”。
[更改] 应用描述精简为“支持HDR的PiliPlus修改版”，适配关于页面的显示空间。
[修复] 修正新安装时震动设置开关显示关闭的问题，与默认开启状态保持一致。
[修复] 移除顶栏、主底栏和浮动底栏顶部边框，避免磨砂材质出现突兀亮线；同时提高轻薄档通透度。

## 历史版本

### v26.8.28.3（2026-08-28，测试构建）

[新增] 外观设置新增磨砂半透明总开关，可控制顶栏、底栏和浮动底栏。
[新增] 提供轻薄、标准、浓厚三档磨砂效果，默认开启并使用标准效果，设置修改即时生效。
[修复] 移除顶栏与手机状态栏交界处的顶部边框，避免出现视觉缝隙。
[修复] 移除主底栏和浮动底栏顶部边框，避免磨砂底栏出现突兀亮线。
[更改] 调低轻薄档遮罩不透明度，使背景透出更多。
[修复] 修正震动反馈设置项初始开关显示为关闭的问题，与默认开启状态保持一致。

### v26.8.28.2（2026-08-28，测试构建）

[更改] 新安装默认开启震动反馈，默认强度为 80；拖动震动强度滑块时即时反馈，取消调节不会保存临时值。
[更改] 两个普通视频默认画质选择顺序调整为 8K、HDR Vivid、杜比视界、HDR 真彩及其他画质。
[更改] “蜂窝网络”设置文案统一改为“移动数据”。
[新增] 顶栏、底栏及普通页面 AppBar 增加磨砂半透明效果。
[更改] Android 正式包改用独立 applicationId `com.maxzrb.piliexo`，并按 `armeabi-v7a`、`arm64-v8a` 分包；Release 启用 R8 与资源压缩。
[修复] 更新器按设备 supportedAbis 精确选择对应 APK，仅在没有架构包时回退通用 APK，避免下载错误架构。
[更改] 应用描述精简为“支持HDR的PiliPlus修改版”，适配关于页面的显示空间。

### v26.8.28.1（2026-08-28）

[新增] Android 在线 UGC/PGC HDR 使用 Media3 原生 SurfaceView 播放，支持 HDR Vivid、杜比视界和 HDR 真彩。
[新增] 所有底栏和侧栏导航项支持可调强度的 Android 原生震动反馈。
[更改] 应用名称、描述、源码入口和更新检查切换为 PiliExo；Android 更新优先使用 AerithDream/PiliExo ModelScope 镜像。
[修复] HDR 播放切换和返回播放列表时的红屏提示及 SurfaceView 残留画面。
[同步] 同步 PiliPlus 基线后的 Flutter 3.47.2、主题初始化、自定义字体及依赖更新；后续不定期同步将在版本记录中单独标注。
