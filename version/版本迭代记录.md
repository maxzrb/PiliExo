# PiliExo 版本迭代记录

## v26.9.2.1（2026-09-02）

[更改] 【重要】因更换 Android 签名密钥，本版本无法覆盖更新旧版，也无法直接覆盖安装；请先备份应用数据，卸载旧版后再安装，卸载可能清除本地数据；安装本版本后，后续同签名版本可直接覆盖更新。
[修复] 修复播放器洞察带宽预估偶尔被缓存空闲返回的 0 覆盖，导致大部分时间不显示；首次未取得有效值时继续显示未测量。
[更改] 应用内更新弹窗针对旧签名版本显示醒目的“无法覆盖更新”警告，并明确卸载重装可能清除本地数据。
[同步] 安全合并 PiliPlus 账户一致性、WBI 视频详情、音频均衡、弹幕下载并发、关注分组排序和账户优化等已审查改动。
[同步] 安全适配 PiliPlus `828de30e9` 字体字重 v2 迁移，以及 `66d1f7d62` 发布/评论输入面板焦点和键盘体验优化。

## v26.9.1.1（2026-09-01）

[修复] 修复 Media3 带宽统计重复计数，避免同一网络传输的字节回调被重复累计导致带宽估计异常偏高。
[更改] Media3 与 mpv 带宽洞察统一约 1 秒刷新，直接显示最新有效原始估计，不使用 5 秒平滑窗口。
[更改] mpv `cache-speed` 只在统一刷新节拍读取；播放、暂停、结束、切换媒体和释放时统一管理刷新状态，非法值不覆盖最近有效值。
[新增] 增加两个后端共用的带宽刷新器及回归测试，验证直接值、刷新节拍、暂停冻结、零值和重置行为。

## v26.8.30.6（2026-08-30）

[同步] 合并 PiliPlus 上游至 2.1.2.3，纳入列表骨架、保存面板、评论回调、字体设置和依赖升级等更新，并保留 PiliExo 的 HDR/Media3、播放器洞察、推荐和更新能力。
[修复] 修复动态与赛事评论底部面板的评论回调上下文传递，避免横屏或嵌套页面中评论详情无法正常打开。
[修复] 修复动态保存二维码 URI 未写入状态的问题，恢复动态链接保存流程。
[修复] 修复字体设置预览默认字重显示不正确的问题。
[更改] 普通播放器画中画入口改用类型安全的原生播放器匹配，同时保留 HDR Media3 原生 SurfaceView 的画中画路径。
[同步] 上游版本同步包含字体设置重构、字体回退、选择区域补丁和动态 URI 解析修复。

## v26.8.30.5（2026-08-30）

[修复] 普通视频播放器洞察接入 mpv `cache-speed` 带宽估计，播放时实时更新，暂停或播放结束后冻结最近一次有效值，切换媒体时清空。
[更改] 普通视频洞察在前向缓冲、时长、实际音视频参数、轨道和视频尺寸变化时刷新；音频优先使用解码输出参数，能够确认 `hw-pixelformat` 时显示硬解。
[修复] 修复音量侧滑在节流期间位移被丢弃导致震动刻度与实际音量不同步的问题，手势结束补提交并处理浮点刻度边界。
[更改] 更新下载回退状态显示实际使用的 ModelScope 镜像源或 GitHub 源，移除无区分度的普通 HTTP 文案。
[新增] 增加普通 mpv 带宽采样器及播放器洞察回归测试。

## v26.8.30.4（2026-08-30）

[新增] 播放器音量和亮度侧滑支持按可配置百分比刻度触发震动，刻度范围为 1%–20%，默认每 3% 触发一次。
[新增] 设置页新增“震动调节”二级弹窗，集中配置底栏/侧栏点击震动、震动强度、音量滑动震动和亮度滑动震动。
[更改] 音量滑动震动默认开启、亮度滑动震动默认关闭；两者沿用统一震动强度设置，其他音量、亮度和横向进度操作保持原行为。

## v26.8.30.3（2026-08-30）

[新增] Media3 明确视频解码/容器错误时按同清晰度 codec、再按更低清晰度切换 Representation，并记录本次播放 session 的 fallback 历史。
[修复] Representation fallback 避免重复尝试，切换时尽量保持播放位置、播放状态、倍速和当前音轨；不再因设备能力预判提前屏蔽 DVH1 等轨道，也不因未报错黑屏主动降级。
[新增] 播放器洞察统一接入 Media3 AnalyticsListener、Format、DecoderCounters 和 mpv/media-kit 实际数据，补充视频/音频 Codec、Codec String、Profile/Level、Dolby Vision、HDR、分辨率/帧率、码率、解码器硬软解、声道、CDN、带宽、掉帧和 fallback 历史。
[新增] 播放设置增加“音频焦点接管”开关，默认开启；关闭时忽略 Audio Focus interruption，但耳机或蓝牙音频断开仍自动暂停。
[更改] Media3 不再独立接管 Audio Focus 或 becoming-noisy，Media3、mpv/media-kit 继续统一使用现有 PlPlayerController 和 AudioSessionHandler。
[测试] 补充 Representation 不循环、同清晰度优先、位置恢复、Telemetry 数据和音频焦点设置相关测试。
