## 楼中楼进度修复

原实现直接用 `loadingState.data.length / count`，存在四个问题：

1. 后续页缺少 `root.count` 时把总数覆盖成 0，进度冻结。
2. 分页重复回复时列表长度大于总数，进度可能超过 1。
3. 刷新或排序不重置进度。
4. 折叠回复、发表回复后不重算进度。

修复：

- 新增 `lib/utils/reply_progress.dart`：总数合并、唯一 id 计数、0..1 clamp。
- 总数只在刷新时采用新值，后续页只允许增大。
- `checkIsEnd` 只在 `count > 0` 时用计数兜底，避免 0 被当成结束。
- 刷新归零；折叠加载、发表回复后调用 `refreshReplyProgress`。
- 新增 `test/fixtures/reply_progress/` 固定输入/参考输出。
