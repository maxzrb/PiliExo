# PiliExo 本机发布工具链

本文件记录本机用于编译和发布的持久化工具链位置。工具链和编译产物不得放入项目 `tmp/`，避免被环境自动清理。

## Flutter SDK（当前：3.47.4）

- 版本：`3.47.4` stable（2026-09-13 起启用，对应 `.fvmrc`）
- 持久路径：`D:\tools\flutter-3.47.4\flutter`
- 压缩包 SHA-256：`31173300481bd06e377fd55ee84214689648b1817563efd7b450b7b78bdf351a`（`flutter_windows_3.47.4-stable.zip`，flutter-io.cn 镜像下载，压缩包保留在 `D:\tools\`）
- 该 SDK 的 framework 已按 `lib/scripts/patch.ps1` 的 android 补丁集打齐 24 个 framework 补丁；material_ui `1.1.0` 的 9 个 material 补丁在 pub 缓存内应用（`tabs.patch` 应用前需把补丁文件转 LF，CI 已内置该步骤）。
- `feature/android-media3-hdr` 及其后续分支（含 `merge/upstream-2.1.4-20260913`）的本地构建、测试、analyze 一律使用 `3.47.4`，**不再使用 `3.47.2`**（旧 SDK 无法满足当前 pubspec 约束，会直接解析失败）。
- 项目版本源仍以 `.fvmrc`、`pubspec.yaml`、`pubspec.lock` 和 `lib/scripts/verify_flutter.ps1` 为准。

PowerShell 发布前设置：

```powershell
$env:FLUTTER_ROOT = 'D:\tools\flutter-3.47.4\flutter'
$flutter = Join-Path $env:FLUTTER_ROOT 'bin\flutter.bat'
$env:Path = "$(Split-Path $flutter);$env:Path"
& .\lib\scripts\verify_flutter.ps1 -FlutterPath $flutter
```

## 持久化发布产物

正式 APK 和校验记录统一放在项目内的 `dist/release/<releaseTag>/`，例如：

```text
dist/release/v26.8.30.6/
├── PiliExo_android_v26.8.30.6_arm64-v8a.apk
├── PiliExo_android_v26.8.30.6_armeabi-v7a.apk
└── SHA256SUMS.txt
```

`dist/` 已被 Git 忽略，产物保留在持久目录但不会进入源码提交。正式签名文件仍只保留在 `android/piliexo-release.jks` 和 `android/key.properties`，两者均不得提交或上传。
